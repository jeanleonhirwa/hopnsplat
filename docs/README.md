## 🎮 About HopNSplat

HopNSplat is a vertical platformer mobile game built with Godot 4.6, featuring:
- Endless vertical climbing gameplay
- Progressive difficulty system
- Power-ups and boost items
- Achievement system
- In-game shop with virtual currency
- AdMob integration for monetization
